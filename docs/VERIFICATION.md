# Проверка выпуска 0.2.0

Дата: **25.10.2026**. Устройство: **Xiaomi MiTV-MOOQ0, Android 11**, 1920×1080. Публичная версия: **0.2.0**, versionCode **3**, пакет `app.twosub.tv`.

## Выполнено

- Release APK собирается; JUnit HistoryPolicy и SeekPolicy: **9 тестов**, без ошибок и пропусков.
- Android release lint проходит без ошибок. Остаются предупреждения о версиях зависимостей, сложности брендового вектора и анализе существующей проверки WebViewFeature.
- **Четыре автономных JS-набора** проверяют каталог/метаданные, качество, историю аккаунта и управление плеером. Проверяются в том числе точная серия и позиция аккаунта, перемотка назад, предпросмотр без сетевых seek, одно подтверждение, отмена с сохранением паузы, sprite-кадры и штатный пропуск заставки. Это выполненные assertions.
- Установщик проверен на успешный путь, режим проверки без установки, неверный хеш, слишком старый Android и конфликт подписи. Ошибочные сценарии не очищают данные.
- Проверены подпись APK, API/версия/ID, четыре ABI, отсутствие `debuggable`, отключение WebView debugging в release, наличие лицензионных уведомлений и соответствие SHA-256 манифесту. Сертификат совпадает с публичным выпуском 0.1.0.
- Проверены публичные файлы и относительные ссылки. Локальные профили, ключи, исходные диагностические снимки и персональные заметки исключены из Git.
- На ТВ: авторизация сохранена после обновления. Проверены каталог, «Новое», «Продолжить», карточка с полным постером, жанры, панель эпизодов и настройки EN/RU. При переходах влево/вправо после вертикальной прокрутки координаты ряда остаются неизменными. В плеере проверены фокус таймлайна, кадр предпросмотра, подтверждение/отмена, сохранение паузы и нативная кнопка пропуска заставки. Нижние текстовые подсказки удалены.
- Экран настоящего QR-входа открыт в изолированной проверочной установке. Для опубликованного скриншота код и QR заменены до захвата; это обозначено на изображении и в документации.

## Что именно устанавливалось на личный ТВ

Чтобы сохранить существующую сессию сопровождающего, release APK для проверки на его ТВ подписан прежним **локальным** ключом. Публичный APK подписан отдельным постоянным **release-ключом**. Это один продукт и один публичный APK; локальный переподписанный файл не распространяется. Android не позволяет просто обновить приложение APK с чужой подписью без миграции/удаления — поэтому личные данные не стирались ради теста.

## Что не заявляется

- Новый цикл подтверждения QR телефоном в этой публикационной проверке не выполнялся; успешный полный вход проверялся ранее при разработке.
- Полный сценарий «посмотреть в браузере → продолжить на ТВ» оставлен для пользовательской проверки. Автоматически проверены разбор авторизованной истории сайта, получение позиции аккаунта и правила объединения с локальными записями.
- Нет полного просмотра каждого фильма, проверки всех провайдеров РФ или всех Android TV-моделей.
- Минимальный API 26 проверен сборкой/lint, а не отдельным физическим устройством с Android 8.0.
- Скриншоты показывают интерфейс, а не гарантируют качество каждого источника видео.
