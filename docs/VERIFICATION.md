# Проверка первого публичного выпуска

Дата: **24.10.2026**. Устройство: **Xiaomi MiTV-MOOQ0, Android 11**, 1920×1080. Публичная версия: **0.1.0**, versionCode **2**, пакет `app.twosub.tv`.

## Выполнено

- Release APK собирается, JUnit HistoryPolicy: 4 теста без ошибок и пропусков.
- Android lint проходит без ошибок. Обнаруженный API 27-only параметр темы убран из общего ресурса для совместимости с minSdk 26. Остаются предупреждения о версиях зависимостей, сложности брендового вектора и анализе уже существующей проверки WebViewFeature.
- Два автономных JS-набора проверяют адаптер: каталог/метаданные и политики плеера. Это выполненные assertions, а не просто загрузка файла.
- Установщик проверен на успешный путь, режим проверки без установки, неверный хеш, слишком старый Android и конфликт подписи. Ошибочные сценарии не очищают данные.
- Проверены подпись APK, API/версия/ID, четыре ABI, отсутствие `debuggable`, `BuildConfig.DEBUG=false`, наличие лицензионных уведомлений и соответствие SHA-256 манифесту.
- Проверены публичные файлы и относительные ссылки. Локальные профили, ключи, исходные диагностические снимки и персональные заметки исключены из Git.
- На ТВ: авторизация сохранена после обновления, работают каталог, «Новое», «Продолжить», карточка с полным постером, жанры, панель эпизодов и настройки EN/RU. MobLand S1E3 открылась в 1920×1080; пауза и возврат сохранили позицию.
- Экран настоящего QR-входа открыт в изолированной проверочной установке. Для опубликованного скриншота код и QR заменены до захвата; это обозначено на изображении и в документации.

## Что именно устанавливалось на личный ТВ

Чтобы сохранить существующую сессию сопровождающего, release APK для проверки на его ТВ подписан прежним **локальным** ключом. Публичный APK подписан отдельным постоянным **release-ключом**. Это один продукт и один публичный APK; локальный переподписанный файл не распространяется. Android не позволяет просто обновить приложение APK с чужой подписью без миграции/удаления — поэтому личные данные не стирались ради теста.

## Что не заявляется

- Новый цикл подтверждения QR телефоном в этой публикационной проверке не выполнялся; успешный полный вход проверялся ранее при разработке.
- Нет полного просмотра каждого фильма, проверки всех провайдеров РФ или всех Android TV-моделей.
- Минимальный API 26 проверен сборкой/lint, а не отдельным физическим устройством с Android 8.0.
- Скриншоты показывают интерфейс, а не гарантируют качество каждого источника видео.
