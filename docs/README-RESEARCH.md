# Почему страница проекта устроена так

Проверено 24.10.2026. Цель — помочь человеку понять пользу, проверить требования и установить приложение. Это дизайн решения, а не измеренный результат A/B-теста; роста конверсии пока никто не измерял.

| Решение | Основание |
|---|---|
| Сначала назначение, реальный экран и скачивание | [GitHub: About READMEs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes) рекомендует объяснить пользу, старт и получение помощи. |
| QR-вход отдельным большим блоком | Это конкретное удобство ТВ-клиента: не надо набирать пароль пультом. Скриншот доказывает наличие экрана. |
| Аккаунт и подписка видны до установки | Пользователь заранее понимает, что APK и доступ сайта — разные вещи. Условия проверены на [2SUB](https://2sub.movie/prices/). |
| Одна кнопка APK с постоянным именем файла | [GitHub: Linking to releases](https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases) описывает `/releases/latest/download/asset-name`. |
| Готовый запрос для Codex, полная инструкция отдельно | Короткий путь для пользователя; подробности подключения не перегружают первый экран. |
| Локальные изображения, alt-тексты и относительные ссылки | README остаётся полезным в клоне и в разных ветках. Изображения не зависят от внешнего хостинга. |
| Короткий FAQ и таблица пульта | Закрывают вопросы до обращения в Issues. Детали разработки вынесены отдельно. |
| Topics и описание репозитория | [GitHub: Topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics) помогает находить проекты по назначению и технологии. |

Не использованы вымышленные отзывы, число пользователей, обещания совместимости со всеми ТВ, фиктивные скорости или заявление «официальное приложение 2SUB». Скриншоты и ограничения должны соответствовать действительному состоянию.
