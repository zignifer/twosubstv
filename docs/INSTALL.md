# Установка 2SUB TV

Нужен Android TV / Google TV с **Android 8.0+ (API 26+)**, интернетом и актуальным Android System WebView. Для просмотра используйте свой [аккаунт 2SUB](ACCOUNT.md). Samsung Tizen, LG webOS и Apple TV этот APK не поддерживают.

## Установить через Codex

Откройте Codex на компьютере в сети телевизора и отправьте:

```text
Установи 2SUB TV из https://github.com/zignifer/twosubstv на мой Android TV.
Прочитай AGENTS.md и docs/INSTALL.md. Проверь модель и Android, выбери мой ТВ
в adb devices, скачай APK из Releases и проверь SHA-256 по release.json.
Обновляй поверх установленного приложения, сохраняя вход и историю.
Для сопряжения и QR-входа скажи, что подтвердить мне на устройстве.
Не меняй мой лаунчер, VPN и другие приложения.
```

Codex поможет подключить телевизор и установить приложение. Подтверждение отладки делается **на ТВ**, подтверждение входа в аккаунт — **на телефоне**. Нельзя подключиться к чужому телевизору только по ссылке на GitHub.

## Подключение телевизора

1. Компьютер и ТВ должны находиться в доступной друг другу локальной сети.
2. Установите [Android SDK Platform-Tools от Google](https://developer.android.com/tools/releases/platform-tools) и распакуйте архив. Команды ниже используют `adb` из этой папки или PATH.
3. Включите режим разработчика штатным способом вашей модели. Обычно он открывается несколькими нажатиями на номер сборки в разделе «Об устройстве».
4. В параметрах разработчика включите доступный способ отладки. Не все прошивки поддерживают одинаковую беспроводную отладку.
5. Если ТВ показывает **«Сопряжение с помощью кода»**, выполните `adb pair IP:ПОРТ_СОПРЯЖЕНИЯ`, введите показанный ТВ код, затем `adb connect IP:ПОРТ_ПОДКЛЮЧЕНИЯ`. Порты могут различаться.
6. Если модель поддерживает обычную сетевую отладку, используйте `adb connect IP:ПОРТ`, указанный в её настройках. Не предполагайте, что порт 5555 доступен на любом ТВ. USB-соединение также подходит, если оно поддерживается моделью.
7. Подтвердите отладку на экране ТВ и проверьте `adb devices -l`: выбранное устройство должно иметь статус `device`.

Используйте текущий адрес **своего** ТВ. Не открывайте ADB в интернет и не настраивайте проброс портов на роутере. После установки отладку можно выключить.

## Установка скриптом на Windows

Скачайте или клонируйте этот репозиторий. В PowerShell из его папки:

```powershell
adb devices -l
.\install.ps1 -Serial 'АДРЕС_ИЛИ_SERIAL_ИЗ_ADB' -AdbPath 'C:\platform-tools\adb.exe'
```

Скрипт проверяет устройство, минимальную версию Android и ТВ-функции, скачивает один APK по фиксированной ссылке из [release.json](../release.json), сверяет SHA-256 и выполняет `install -r`. Он не удаляет приложение, не чистит его данные и не меняет другие приложения. При нескольких устройствах `-Serial` обязателен всегда.

Предварительная проверка без установки:

```powershell
.\install.ps1 -Serial 'АДРЕС_ИЛИ_SERIAL_ИЗ_ADB' -ValidateOnly
```

## Установка вручную

Скачайте **`2sub-tv.apk`** и **`SHA256SUMS.txt`** из [последнего релиза](https://github.com/zignifer/twosubstv/releases/latest). `Source code.zip` — исходники, не установщик.

Проверьте хеш файла. В PowerShell:

```powershell
Get-FileHash .\2sub-tv.apk -Algorithm SHA256
```

В Linux: `sha256sum 2sub-tv.apk`; в macOS: `shasum -a 256 2sub-tv.apk`. Результат должен совпадать с `SHA256SUMS.txt` и `release.json` для той же версии. Если доступны Android Build-Tools, дополнительно проверьте подпись командой `apksigner verify --verbose --print-certs 2sub-tv.apk` и сравните SHA-256 сертификата с `release.json`.

Затем установите на явно выбранное устройство:

```text
adb -s SERIAL install -r 2sub-tv.apk
adb -s SERIAL shell am start -n app.twosub.tv/.MainActivity
```

Можно перенести APK на ТВ через USB-накопитель или локальную передачу файлов и открыть его файловым менеджером. Разрешение установки из этого источника выдаётся в настройках ТВ. Конкретные названия пунктов зависят от прошивки.

## После установки

Откройте 2SUB TV, проверьте навигацию стрелками и выберите «Войти в аккаунт». [Отсканируйте QR телефоном](ACCOUNT.md#вход-на-телевизоре), подтвердите вход и запустите доступное вашему аккаунту видео. Проверьте паузу, перемотку и языки субтитров. Успешная установка APK сама по себе не проверяет воспроизведение.

## Обновление

Повторите установку новым APK из этого репозитория с `adb install -r`. Постоянная подпись позволяет сохранить вход, историю и настройки. Удалять приложение перед обновлением не нужно.

`INSTALL_FAILED_UPDATE_INCOMPATIBLE` означает несовпадающую подпись, например после собственной debug-сборки. **Не удаляйте существующее приложение автоматически**: это сотрёт его данные. Используйте обновление от того же издателя / с тем же ключом; переход между чужими подписями требует отдельного решения владельца устройства.
