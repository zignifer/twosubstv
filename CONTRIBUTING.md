# Участие в проекте

Сообщения об ошибках и предложения приветствуются. Для начала прочитайте [AGENTS.md](AGENTS.md), [сборку](docs/BUILD.md) и [ограничения](CHANGELOG.md).

В issue укажите модель ТВ, Android, версию приложения, шаги и ожидаемое поведение. Не присылайте аккаунты, cookies, QR-коды, подписанные ссылки на видео или платёжные данные.

В pull request опишите проблему и результат изменения. Сохраните четыре режима субтитров, управление пультом, стабильные размеры фокуса и границы WebView. Для изменения интерфейса приложите безопасные скриншоты; для логики — подходящую проверку. Укажите, какие сценарии реально прошли на ТВ и какие ещё не проверены.

Исходники сайта, чужие потоки и пользовательские профили в этот репозиторий не добавляются. Ключи подписи релизов остаются у сопровождающего.
